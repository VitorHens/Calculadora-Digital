# 🧮 Calculadora Digital

Aplicação web desenvolvida em PHP com Programação Orientada a Objetos, Slim Framework e Bootstrap.

## Funcionalidades

- Cálculo de IMC
- Controle de estoque
- Média escolar
- Cálculo de salário
- Cálculos de triângulos

## Tecnologias

PHP • HTML5 • Bootstrap • Slim Framework • Composer • POO

Desenvolvido por **Vitor Hens**.
